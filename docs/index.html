Overview

What is it?

Agent Board is a local supervisory dashboard where you observe and guide a fleet of AI agents collaborating on software development tasks. Each card is a user story; each column is a stage owned by a specialized agent.

📋
You create, agents deliver
Write a card title, description, and acceptance criteria. Click Start. Agents handle the rest autonomously.
🔍
Full transparency
Every agent action is logged with timestamps, reasons, and artifacts. Nothing is hidden.
🎮
You stay in control
Leave comments to steer agents. Unblock stuck cards. Archive completed work. Intervene at any point.
💾
100% local
SQLite for state. No cloud, no auth, no external services beyond the Anthropic API.
Workflow

The pipeline

Cards flow left to right through six columns. Each column has a dedicated agent; when a card enters, the agent automatically picks it up, processes it, and advances it — or blocks it with a reason.

The team

Six specialized agents

Each agent has a distinct role, system prompt, tool allowlist, and column ownership. You can edit all of these — or create your own agents — directly from the board.

▲

Card lifecycle

What happens step by step

From the moment you click "Start" to the card landing in Done, here is exactly what the system does.

1
You create and start a card
Give the card a title, description, and acceptance criteria in the New Card modal. The card lands in Backlog. Click Start on the first Backlog card to kick off the pipeline — it moves immediately to Specification.
2
The orchestrator fires card:entered
Whenever a card moves to a new column, the server emits a card:entered event. The orchestrator picks it up, finds which agent owns that column, and spawns a Claude CLI subprocess.
3
Claude receives context and works
The agent runs as claude --print with a system prompt (the agent's role + outcome contract) and a user prompt containing the full card context: title, description, acceptance criteria, activity history, and any comments. 
# Card context sent to the agent:
## Card US-07: Add dark mode toggle

Description: Users need a persistent dark/light mode toggle...

Acceptance criteria:
- [ ] Toggle visible in header
- [ ] Preference saved to localStorage
- [ ] Respects prefers-color-scheme on first visit

Recent activity:
→ Scribe wrote spec: "dark-mode-spec.md"
4
Agent returns a structured outcome
The agent must end its response with a fenced JSON block. The server parses this to decide what happens next. Missing or malformed outcomes default to advancing the card. 
```agent-board-outcome
{
  "advance": true,
  "artifacts": [
    { "kind": "spec", "title": "dark-mode-spec.md" }
  ],
  "acceptanceUpdates": [0, 1, 2]
}
```
advance: true
Card moves to next column automatically. Artifacts and acceptance updates are recorded.
block: true
Card stays in current column, marked BLOCKED with the agent's reason. You must unblock manually.
5
Real-time broadcast to the frontend
Every state change — card moved, blocked, artifact added, acceptance item checked — is immediately broadcast over WebSocket. The React store updates without any polling. The Activity Feed panel captures every event with timestamps.
6
You observe, comment, or intervene
Open any card to see its full activity timeline, artifacts, and acceptance criteria. Leave a comment addressed to the next agent to steer their work. If a card is blocked, read the reason and click Unblock when ready. Archive completed cards from Done to keep the board clean.
Architecture

How it's built

A pnpm monorepo with three packages. The frontend and backend are fully decoupled — they communicate only through REST and WebSocket.

Browser (React + Vite :5173) │ │ REST ──────────────────► Fastify API :4000 │ │ │ WebSocket ◄──────────────── │ • /api/cards │ │ • /api/agents │ │ • /api/columns │ │ • /api/config │ │ │ │ │ Orchestrator │ (event bus) │ │ │ │ card:entered │ ▼ │ Agent Runtime │ │ │ │ claude --print subprocess │ │ (per card, per column) │ ▼ │ Claude CLI │ (Anthropic API) │ │ │ │ structured outcome JSON │ ▼ │ SQLite (WAL) │ data/agent-board.db │ └── Shared types: @agent-board/types (Card, Agent, Column, WsEvent, ...)
apps/web
React 18 + Vite 5. Custom Graphite design system with CSS variables. No UI library — pure hand-crafted components.
apps/server
Fastify 5 + better-sqlite3. Zod for body validation. Event bus (EventEmitter) for orchestration. WAL mode for concurrent reads.
packages/types
Shared TypeScript interfaces: Card, Agent, ColumnDef, WsEvent, CardDetail. Both apps import from here — one source of truth.

Getting started

Setup in 3 steps

Prerequisites: Node.js ≥ 20, pnpm, and the Claude Code CLI installed and authenticated.

📦

Install dependencies

From the repo root, install all workspace packages at once.

pnpm install
🔑

Configure API key

Skip this step if you're already authenticated via claude login.

cp .env.example .env
# Edit .env:
ANTHROPIC_API_KEY=sk-ant-...
🚀

Start the dev server

Starts both the frontend (port 5173) and backend (port 4000) in parallel.

pnpm dev

Open http://localhost:5173

Environment variables
Variable Default Description
ANTHROPIC_API_KEY — Required unless authenticated via claude login
CLAUDE_CODE_BIN claude Path to the Claude CLI binary if not in PATH
CLAUDE_CODE_WORK_DIR process.cwd() Directory where agents perform file read/write/bash operations. Also configurable at runtime via Settings in the UI.
